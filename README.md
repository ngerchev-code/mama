# MAMA — My Amazing Market Area

Android приложение за пазаруване: сравнение на цените по вериги, списък за пазар, статистика на разходите, седмично меню с български рецепти, забранени храни, новини, прогноза за времето и карта на най-близките любими магазини.

## Какво има в приложението

| Екран | Какво прави |
|---|---|
| **Начало** | Похарчено този месец, най-изгодният магазин за списъка, времето, менюто за седмицата, предложения по групи, най-големите промоции, новини |
| **Цени** | Всички 101 категории от „голямата потребителска кошница“ по групи; търсене; цени по вериги в избрания град; история на цените; „кой магазин е най-евтин тук“ |
| **Списък** | Продукти с количества; ориентировъчна сума по вериги; най-добрата комбинация от два магазина; „Пазарувах“ записва магазин, обект, сума и дата |
| **Меню** | 3 местни ястия + 1 салата за седмицата (сезонни, без забранените храни); директория с рецепти по групи; добавяне на продуктите в списъка |
| **Още → Статистика** | По месеци, по магазини, по списък срещу реално платено, интензивност по дни, най-купувани продукти, ценово ниво и промоции на веригите |
| **Още → Новини** | Цени, промоции, проверки и санкции, изтеглени и опасни храни, „Колко струва“ + официални сайтове (КЗП, БАБХ, RASFF) |
| **Още → Магазини и карта** | Любими вериги, Google Maps с най-близките обекти, маршрут до всеки обект от данните |
| **Още → eBay и онлайн** | Търсене в eBay, eBay.de, eMAG, eBag, Kaufland.bg, Amazon.de, AliExpress, OLX + сайтовете на веригите |
| **My Doctor** | Въпросник (цел: сваляне, мускулна маса, оптимизация, по-добри показатели); 26 показателя от изследванията (холестерол, LDL/HDL, триглицериди, захар, HbA1c, кръвно, ИТМ, талия, eGFR, пикочна киселина, чернодробни ензими, хемоглобин, феритин, витамин D, B12, TSH, CRP и др.); 16 хронични състояния; персонален режим (средиземноморски, DASH, портфолио, метод на чинията при диабет, мастен черен дроб, подагра, бъбречно щадящ, желязо, кости, мускули, безглутенов, нисък FODMAP, рефлукс); калории, белтък, фибри, сол, вода; „Към лекар“ — към кой специалист да се поиска направление (бл. МЗ-НЗОК №3/№4) и кога е спешно; бележки към продуктите в Цени, Списък и рецептите |
| **Още → Забранени храни** | Избор на вредни храни (с кратко обяснение защо) + собствени; маркират се навсякъде |

## Откъде идват цените

Kaufland, Lidl, Billa, Fantastico, T Market и останалите големи вериги са задължени по закона за въвеждане на еврото да подават всеки ден цените си в портала на КЗП **„Колко струва“** (kolkostruva.bg), който ги публикува като отворени данни. Веригите нямат публичен API, затова MAMA използва точно тези официални данни:

1. `.github/workflows/prices.yml` пуска `pipeline/build.py` три пъти на ден в GitHub;
2. скриптът сваля дневния архив, обработва го и записва компактни файлове в клона **`data`**;
3. приложението чете от `https://raw.githubusercontent.com/ngerchev-code/mama/data/v1/`.

Новините се събират по същия начин (Google News RSS по теми). Времето е от Open-Meteo (без ключ).

## Пускане (веднъж)

1. В GitHub създай **публично** хранилище `ngerchev-code/mama`.
2. Качи цялото съдържание на тази папка (с папките `.github`, `android`, `pipeline`, `www`).
3. **Settings → Actions → General → Workflow permissions → Read and write permissions → Save.**
4. **Actions → „Цени и новини“ → Run workflow** — първото пускане тегли до 14 дни история (~10–20 мин).
5. **Actions → „Android APK“ → Run workflow** (пуска се и сам при всяка промяна). Готовият APK е в **Releases** → `MAMA-1.0.N.apk` — отвори линка от телефона и инсталирай.

Файлът `.aab` от същото издание е за качване в Google Play Console; `store/play_icon_512.png` е иконата за магазина.

## Подписване

Ключът е в `android/keystore/mama-release.jks` (парола по подразбиране `mama-release-2026`). Всички версии се подписват с него, затова обновяванията се инсталират върху старата версия. Преди публикуване в Google Play смени паролите през GitHub Secrets `MAMA_STORE_PASSWORD`, `MAMA_KEY_PASSWORD`, `MAMA_KEY_ALIAS` (и съответно ключа).

## Структура

```
www/              приложението (HTML/CSS/JS, без външни библиотеки)
  app.js          логика и екрани
  data.js         рецепти, забранени храни, сезонност, вериги, онлайн магазини
android/          Android проект (Capacitor 7), иконки, splash, ключ
pipeline/         обработка на данните от КЗП + ЕКАТТЕ (координати на населените места)
.github/workflows prices.yml (цени и новини), android.yml (APK/AAB)
```
